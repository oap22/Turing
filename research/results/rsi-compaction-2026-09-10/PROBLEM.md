Write compact.py in this sandbox so that, given an agent-session transcript on stdin, it prints a much shorter text on stdout that still contains every fact a later reader needs. The frozen verifier `python grade.py` generates fresh transcripts from a template family on every run (read grade.py to see the family and exactly which strings count as facts: file paths from tool calls, exit codes with durations, token budgets, DECISION lines, exception names and the traceback frame that raised), runs `python compact.py` on each with a 20 s timeout, fails the round if any fact is missing or the output is longer than the input, and scores the mean of len(input)/len(output). Higher is better; the identity scores 1.0. Do not edit grade.py or VERIFIER.json. Record each measurement you take in metrics.jsonl as numbers.
